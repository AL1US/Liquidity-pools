# Liquidity Pool
это проект, разработанный для управления ликвидностью в децентрализованных финансовых приложениях. Он позволяет пользователям взаимодействовать с пулом ликвидности и эффективно управлять своими активами.

### Factory
Содержит в себе конструктор, который деплоит все остальные контракты

### Pools
Содержит в себе функции обмена токенов

### Token
Шаблонный контракт, на основе которого деплоятся все токены системы

### Staking
Контракт на который можно положить свои LP токены с целью увелечения капитала

### Router
Контракт, который создаёт правильные маршруты для обмена двух токенов, из разных пулов

# Запуск hardhat

Для запуска локальной сети hardhat 

Инициализацися проекта
```
npx hardhat --init
```
Перед повторным запуском сети, её нужно всегда чистить
```
npx hardhat clean
```
Запуск сети
```
npx hardhat node
```

В другом терминале:

Установить зависимости openzeppelin
```
npm install @openzeppelin/contracts
```
Компиляция
```
npx hardhat compile
```
Деплой - специальный скрипт 
```
npx hardhat run --network localhost scripts/deploy.js
```
